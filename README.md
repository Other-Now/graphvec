# graphvec

A small sharded property-graph + vector store in C++20: CSR graph storage with a WAL, a Cypher subset differentially tested against Memgraph, a from-scratch HNSW index benchmarked against hnswlib and FAISS, and etcd-lease primary-backup replication with fencing tokens, checked with Porcupine.

Work in progress; results land here once CI has produced them.
